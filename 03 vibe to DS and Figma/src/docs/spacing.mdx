# Spacing, radius, shadow, layout, motion

## Spacing

A 4px grid. Tailwind multiplies `--spacing` (0.25rem), so `p-4` is 16px. In Figma, `spacing/1_5` is `p-1.5`: DTCG and Figma names cannot contain dots.

<ScaleTokens group="spacing" />

## Radius

Whole pixels. The original app derived these from `--radius × 0.6 … 2.6`, which produced 4.8, 6.4, 11.2px and so on.
